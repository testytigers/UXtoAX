The AI tools landscape for designers moves fast and overpromises regularly. This is not a comprehensive list of everything that exists — it's a practitioner's guide to what's actually changing design workflows in 2025.

## For research synthesis

**Claude (Anthropic)** has become the preferred tool for research synthesis among practitioners who work with long documents. Its 200k context window means you can upload a full set of interview transcripts and ask coherent questions across all of them. Use it for:

- Surfacing recurring themes across multiple interviews
- Identifying contradictions between what users say and what they do
- Generating research discussion guides from a brief
- Synthesising competitor analysis from multiple sources

The key discipline: treat Claude's synthesis as a first draft, not a conclusion. It's fast and often surprisingly insightful, but it misses things. Always review the primary sources.

**Dovetail AI** has added solid AI-assisted tagging and insight generation. If you're already in Dovetail for storage and collaboration, its AI features are worth using for theme clustering and highlight extraction.

## For design work

**Figma AI** is genuinely useful for narrow tasks. Variant generation saves real time when you need to explore a set of options quickly. The microcopy tools are hit-or-miss but useful as a starting point. The layout suggestions are best ignored — they don't know your design system.

**v0 by Vercel** is exceptional for prototyping if you're comfortable with components. Describe a UI and it generates working code. For AX work, this is particularly useful for prototyping the agent interface layer — the scaffolding around the conversation, not the conversation itself.

**Galileo AI** is worth watching for wireframe generation from briefs. It's not production-ready, but for exploratory phases and quick concept validation it removes the blank-canvas friction.

## For AX-specific work

**Voiceflow** is the most mature tool for conversation flow design. It lets you map agent interactions visually, test flows with real LLM calls, and hand off specifications to engineering. If you're designing conversational experiences, this is close to a required tool.

**FigJam + AI** works well for agent behavior mapping. Use it for the structural thinking — agent states, decision trees, escalation paths — before you get into detailed specification.

**Working directly with models** remains the most effective prototyping method for AX work. Build a system prompt, run a session with a user (or yourself), and annotate where the interaction breaks. It's rough, but it gets you to real failure modes faster than any tool that abstracts away from the model.

## What's not worth your time right now

AI image generation tools have limited practical utility for UX work — the outputs aren't production-ready for UI, and using AI-generated images in user research introduces confounds. Useful for mood boards, not much else.

Most "AI wireframing" tools that generate full-page layouts from briefs are not at the point where the output is faster to work with than starting from scratch. The quality isn't there yet.

The plugin ecosystem for "AI UX" in Figma is largely noise. A handful are useful for specific tasks; most are demos. Evaluate with a specific workflow problem in mind, not as a general productivity play.

## The meta-skill

The most valuable AI skill for a UX designer isn't proficiency with any single tool — it's **good prompting as design practice**. How you describe a problem to an AI, how you structure your questions, how you iterate on outputs — these are design skills applied to a new medium.

That's also, not coincidentally, foundational to AX design. The designer who can craft a clear brief for an AI is developing the same cognitive muscle as the designer who will define agent behavior specifications. Start there.
