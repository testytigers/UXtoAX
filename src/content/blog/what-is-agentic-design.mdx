The interface is no longer just what users see. It's what the agent does.

Agentic design is the practice of defining how AI systems perceive context, make decisions, and take actions on behalf of the people who deploy them. It's distinct from traditional UX in one fundamental way: the system acts, not just responds.

## The shift from reactive to proactive

Classic UX design is reactive by default. A user clicks, types, swipes — the product responds. The designer's job is to make that response useful, clear, and delightful.

Agentic systems flip this. The agent can initiate. It can decide to send an email, book a meeting, draft a document, or escalate a ticket — without the user explicitly requesting each step. The designer must now account for what the system chooses to do, not just what it says.

## What agentic designers actually define

When you design an agent, you're not designing screens. You're designing behavior. Specifically:

**Goals and scope** — What is this agent trying to accomplish? What is explicitly out of scope? These boundaries define how the agent interprets ambiguous instructions.

**Perception** — What does the agent have access to? Calendar, email, documents, browsing? What it perceives shapes what it can do.

**Decision logic** — Under what conditions does the agent act versus ask? This is the core design challenge. An agent that asks too much is annoying. One that acts too much is dangerous.

**Failure behavior** — What does the agent do when it's uncertain, when tools fail, or when the situation falls outside its training? Failure states are first-class design decisions.

**Trust calibration** — How does the user know what the agent did? How do they audit, correct, or override it?

## Why UX designers are ready for this

The skills that make someone a good UX designer — systems thinking, user research, information architecture, edge case sensitivity — are exactly what agentic design requires.

The difference is that you're designing a collaborator, not a tool. That's a mental model shift, not a skill shortage.
