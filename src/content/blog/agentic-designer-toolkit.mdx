Every generation of designers has a primary tool that shapes how they think. Desktop designers had Photoshop. Web designers had Dreamweaver. UX designers had Figma and its predecessors. Agentic designers are still figuring out what their primary tool is — which means now is the time to understand the landscape.

## What Figma still does well

Surface design: how outputs are rendered, what dashboards look like, how users interact with the wrapper around the AI. Figma handles this.

Collaborative review and annotation: the tool's strength is multiplayer design review. That doesn't change when the design object changes.

Prototyping user journeys: for the parts of an AI product that involve defined screens and flows, Figma prototypes still communicate intent effectively.

## What Figma doesn't do

It has no native representation for agent behavior, decision logic, or conditional state. You can simulate a chatbot interface, but you can't represent what the agent does when a tool call fails, or how it handles ambiguous input at message three. The medium doesn't exist.

## The emerging toolkit

**Mermaid / Lucidchart / FigJam** — For decision trees, state diagrams, and flow documentation. Mermaid is particularly useful because it's text-based and version-controllable.

**Notion / Linear documents** — For behavior specifications. Most teams are writing behavior specs as structured documents, not in dedicated tools.

**Cursor / Replit / v0** — For designers who want to build functional prototypes of AI interfaces. The bar to working code has dropped significantly; many AX designers are prototyping in code rather than Figma.

**LLM APIs directly** — For prototyping agent behavior. The fastest way to test a conversation design is to implement a rough version with a direct API call and test it with real users.

**Prompt testing environments** — PromptLayer, Weights & Biases, and similar tools for testing prompt designs against a range of inputs. These are engineering tools that designers are increasingly adopting.

## The meta-skill

Tool fluency matters less than conceptual clarity. A designer who can precisely specify agent behavior in a Notion document will outperform a designer who knows six tools but can't articulate what the agent should do when a user contradicts themselves.

Learn the tools that let you communicate your design thinking clearly to the people who build with you. Everything else is secondary.
